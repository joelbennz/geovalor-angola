# Geovalor Angola

Site institucional da Geovalor Angola, Lda. — empresa angolana de serviços geofísicos e energéticos.

## Estrutura

- `index.html`, `styles.css`, `script.js`, `cinematic.css` — código-fonte editável do site (raiz).
- `assets/` — imagens, gráficos de dados e scripts de secções interativas.
- `brand/` — logótipo e variantes de marca (SVG/PNG).
- `GeoValor-Brand-Kit/` — kit de marca organizado (logótipos, cores/tipografia, fotografia, manual).
- `flyers/` — materiais para Instagram/LinkedIn.
- `identidade-visual-extraida/` — entrega de identidade visual.
- `release/` — build final pronto para publicação (HTML autónomo + assets + `robots.txt`/`sitemap.xml`/`site.webmanifest`), usado no deploy para `geovalor-angola.com`.

## Deploy

O conteúdo de `release/` é publicado em `geovalor-angola.com` (Hostinger) via SSH.
