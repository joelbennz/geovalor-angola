# Geovalor — primeira direção visual

## Conceito

O símbolo combina três camadas de curvas de nível com um `V` central. As curvas representam território, profundidade e leitura geofísica; o `V` representa valor, validação e visão técnica.

## Paleta inicial

- Basalto: `#111311`
- Marfim mineral: `#E7E6DF`
- Cobre oxidado: `#C98252`

## Ficheiros

- `geovalor-logo.svg` — versão horizontal para cabeçalho, apresentações e propostas.
- `geovalor-mark.svg` — símbolo isolado para favicon, avatar e equipamento.
- `geovalor-logo-mono.svg` — aplicação a uma cor para carimbos, documentos e gravação.

Esta é uma primeira direção e deve ser validada antes de expandir para papelaria, viaturas, capacetes e sinalética.

## Explorações adicionais

- `geovalor-logo-option-02.svg` — Sinal Profundo: onda sísmica e leitura geofísica.
- `geovalor-logo-option-03.svg` — Estratos: camadas geológicas num escudo hexagonal.
- `geovalor-logo-option-04.svg` — Coordenada: precisão de levantamento e monograma GV.
- `logo-options.html` — prancha comparativa das quatro direções.
